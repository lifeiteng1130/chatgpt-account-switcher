# ChatGPT Windows 本地账号切换器

双击 `ChatGPTAccountSwitcher.exe` 启动图形界面，不显示命令行窗口，也可以通过桌面上的“ChatGPT 账号切换器”快捷方式打开。要固定到任务栏，右键单击该 `.exe`，选择“显示更多选项”→“固定到任务栏”（不同 Windows 版本菜单可能略有不同）。启动失败时会显示错误提示。界面使用背景图片和磨砂玻璃风格的卡片、按钮。仅适用于当前 Windows 用户，使用官方桌面应用的 `%USERPROFILE%\.codex\auth.json` 登录文件。

## 更换背景

点击左侧“切换背景”选择 PNG、JPG、BMP 或 GIF 图片。工具会按比例缩小到最多 1800×1200，再转换为 PNG，保存在 `%LOCALAPPDATA%\ChatGPTAccountSwitcher\background.png`，立即应用并在下次启动时继续使用；选择的原图不会修改，导入的私人图片不会写入项目目录或上传。要恢复默认图，可再次点击“切换背景”并选择项目中的 `assets\background.png`。建议使用横向图片；工具会按窗口比例居中裁剪。手动替换已保存的图片后，点击“刷新状态”即可重新加载。

## 首次使用

1. 在官方 ChatGPT/Codex 应用中正常登录账号 A。
2. 打开切换器，点“保存当前登录”，输入不含邮箱或密码的备注（例如 `work`）。若登录令牌含邮箱，卡片会自动显示 `邮箱 · 备注`；取不到邮箱时仅显示备注。
3. 完全退出官方应用和所有 Codex 任务，在切换器中点击“添加下一个账号”。工具会加密保存 A 的恢复记录，并暂时移走登录文件；**不要点击官方应用的“退出登录”**。
4. 重新打开官方应用。若显示登录页，登录账号 B；登录完成后完全退出应用，再点切换器中的“完成添加并保存”，输入另一备注（例如 `personal`）。若仍自动进入 A，或不想继续，关闭应用后点击“恢复先前账号”。
5. 以后切换时，先结束所有 ChatGPT/Codex 任务并**完全退出桌面应用**。点击目标账号卡片，点“切换到所选账号”。然后从 Windows 开始菜单重新打开官方应用，核对显示的账号。

切换器不会自动注销、强制结束进程或启动应用。网页端会话不共享；本地会话数据库不会被复制或删除。每个账号须至少经过一次正常登录，失效的会话仍需重新登录并重新保存标签。

## 账号垃圾箱

完全退出 ChatGPT/Codex 后，可以在非当前账号卡片上点击“移到垃圾箱”。此操作只移动切换器保存的加密账号记录，不会注销官方应用，也不会删除本地聊天记录。当前登录账号、无法确认当前账号时，以及“添加下一个账号”流程未完成时，均不能移除账号。

左侧“查看垃圾箱”可恢复账号，或再次确认后永久删除。恢复时如果同名备注已被其他保存记录占用，会拒绝覆盖；垃圾箱不会自动清空。如果垃圾箱中的账号后来变成当前登录账号，也会拒绝永久删除。永久删除仅清除该账号在垃圾箱中的加密保存记录，此后如需切换到该账号，可能需要重新登录并保存。

## 存储与安全

- 账号凭据加密存放在 `%LOCALAPPDATA%\ChatGPTAccountSwitcher\profiles`，使用 Windows DPAPI CurrentUser；换 Windows 用户、重装系统后通常无法解密。
- 垃圾箱位于账号库的 `trash` 子目录；文件仍是 DPAPI 加密内容，不是 Windows 回收站，也不会被同步到 Git。
- 邮箱只从本地 `id_token` 读取并用于卡片显示，不写入文件名、不上传，也不参与切换校验；备注仍是保存资料的标签。
- 官方应用仍需要自己的 `%USERPROFILE%\.codex\auth.json`，这是明文敏感文件，不应发送给别人。
- 切换只改 `auth.json`；加密的 `recovery-*.dpapi` 副本留在账号库中。不要把账号库上传到网盘或 Git。
- 添加账号期间的 `add-account.dpapi` 是加密恢复记录；完成保存或恢复后自动移除。请勿手动删除。
- 工具不限制桌面应用版本，仍会检查应用进程和登录文件格式。应用升级后若凭据格式或账号状态管理发生变化，可能需要调整工具。

## 已知限制

当前版本只确认 `auth.json` 的身份字段与令牌结构；官方应用可能还维护其他私有账号状态。因此切换后必须人工核对 UI 显示的账号，不能把本工具当成已获官方支持的多账号功能。若账号显示不符，保持应用关闭，通过工具选择目前 `auth.json` 对应的标签切回；不要反复尝试覆盖。此版本不会自动验证 UI 账号或自动回滚登录失败。

如果切换中断或无法切回，停止使用，保留 `%LOCALAPPDATA%\ChatGPTAccountSwitcher\profiles` 及 `%USERPROFILE%\.codex` 原样，再寻求恢复协助。切勿删除 `sessions`、SQLite 文件或重置官方应用。

## 开发验证

使用 Windows PowerShell 5.1 执行：

```powershell
./Build-Launcher.ps1
Invoke-Pester -Script '.\tests\*.Tests.ps1'
```

构建脚本使用 Windows 自带的 .NET Framework C# 编译器和 Windows PowerShell 程序集，不需要安装额外依赖。`ChatGPTAccountSwitcher.exe`、`Start-Switcher.ps1`、`AccountSwitcher.psm1` 和预编译的 `LiquidGlass.Controls.dll` 应保留在同一目录；DLL 缺失或比源码旧时会临时编译控件，启动会慢一些。

测试使用假登录数据，不能证明官方应用中的真实双账号切换已成功。
