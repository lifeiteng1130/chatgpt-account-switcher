# ChatGPT Windows 本地账号切换器

双击 `打开账号切换器.cmd` 启动图形界面。界面采用深色侧栏、浅色主区和账号卡片。仅适用于当前 Windows 用户和已检查的官方桌面版 `OpenAI.Codex 26.1002.7124.0`。

## 首次使用

1. 在官方 ChatGPT/Codex 应用中正常登录账号 A。
2. 打开切换器，点“保存当前登录”，输入不含邮箱或密码的备注（例如 `work`）。若登录令牌含邮箱，卡片会自动显示 `邮箱 · 备注`；取不到邮箱时仅显示备注。
3. 完全退出官方应用和所有 Codex 任务，在切换器中点击“添加下一个账号”。工具会加密保存 A 的恢复记录，并暂时移走登录文件；**不要点击官方应用的“退出登录”**。
4. 重新打开官方应用。若显示登录页，登录账号 B；登录完成后完全退出应用，再点切换器中的“完成添加并保存”，输入另一备注（例如 `personal`）。若仍自动进入 A，或不想继续，关闭应用后点击“恢复先前账号”。
5. 以后切换时，先结束所有 ChatGPT/Codex 任务并**完全退出桌面应用**。点击目标账号卡片，点“切换到所选账号”。然后从 Windows 开始菜单重新打开官方应用，核对显示的账号。

切换器不会自动注销、强制结束进程或启动应用。网页端会话不共享；本地会话数据库不会被复制或删除。每个账号须至少经过一次正常登录，失效的会话仍需重新登录并重新保存标签。

## 存储与安全

- 账号凭据加密存放在 `%LOCALAPPDATA%\ChatGPTAccountSwitcher\profiles`，使用 Windows DPAPI CurrentUser；换 Windows 用户、重装系统后通常无法解密。
- 邮箱只从本地 `id_token` 读取并用于卡片显示，不写入文件名、不上传，也不参与切换校验；备注仍是保存资料的标签。
- 官方应用仍需要自己的 `%USERPROFILE%\.codex\auth.json`，这是明文敏感文件，不应发送给别人。
- 切换只改 `auth.json`；加密的 `recovery-*.dpapi` 副本留在账号库中。不要把账号库上传到网盘或 Git。
- 添加账号期间的 `add-account.dpapi` 是加密恢复记录；完成保存或恢复后自动移除。请勿手动删除。
- 工具只检查已知版本。应用升级后会拒绝切换，需要重新检查兼容性。

## 已知限制

当前版本只确认 `auth.json` 的身份字段与令牌结构；官方应用可能还维护其他私有账号状态。因此切换后必须人工核对 UI 显示的账号，不能把本工具当成已获官方支持的多账号功能。若账号显示不符，保持应用关闭，通过工具选择目前 `auth.json` 对应的标签切回；不要反复尝试覆盖。此版本不会自动验证 UI 账号或自动回滚登录失败。

如果切换中断或无法切回，停止使用，保留 `%LOCALAPPDATA%\ChatGPTAccountSwitcher\profiles` 及 `%USERPROFILE%\.codex` 原样，再寻求恢复协助。切勿删除 `sessions`、SQLite 文件或重置官方应用。
